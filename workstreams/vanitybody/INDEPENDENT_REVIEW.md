# Independent Review — Portable VanityBody Checkpoint

**Scope:** Public fixtures, configuration boundary, and algorithm behavior in
`workstreams/vanitybody`. This is not a review of local evidence, extracted
assets, meshes, package contents, route ownership, or gameplay.

## Result

The public workstream exposes a fail-closed correction-anchor contract and
synthetic clearance/position-patch algorithm. The contract names only the five
approved root-template/mode pairs and retains protected modes as an exclusion
boundary. Portable execution uses declared synthetic NumPy fixtures and does
not read ignored evidence, staging, ledgers, or private configuration at import
time.

Private integration is opt-in through `local/config.json`. It requires explicit
local input files and constrains generated output to `local/generated/`; an
absent or invalid configuration raises `LocalIntegrationUnavailable`. Tests
that require local route, GLB, UUID-audit, or ledger inputs are skipped with
that reason when configuration is absent.

## Limits

The synthetic solver demonstrates only algorithm behavior. It does not prove a
garment/body boundary, clearance for any real asset, a mesh correction,
topology or semantic preservation for a real GR2, package validity, coverage,
protected-control preservation, route validity, or gameplay acceptance.

No corrected GR2, PAK, visual-bank override, live-game action, or gameplay
result is included or reviewed by this checkpoint.
