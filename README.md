# New Body and Clothing Morph

Class-first continuation of the Baldur's Gate 3 Body and Clothing Morph project.

## Current status

Design and implementation planning are in progress. No package in this repository is gameplay-approved, and generated PAK/GR2 artifacts are intentionally excluded from Git.

The project separates:

- true `Underwear`-slot items;
- `VanityBody` clothing and confirmed groin/genital corrections;
- complete SCO/Sindae garment inventory, class reconciliation, and test queues.

Static tests, manifests, hashes, and package extraction prove only offline/package properties. Gameplay success requires an exact active profile, route evidence, and Alan's visual acceptance.
