# Coverage Status — Public Boundary

The publishable workstream is a portable, fail-closed algorithm and synthetic-fixture test surface. It does not publish local inventory results, generated evidence, route identities, source paths, package metadata, test cards, or archived cards.

The absence of a ready record in the portable fixtures is not a statement about any real garment. Local source generation is opt-in through `COVERAGE_LEDGER_LOCAL_CONFIG`, with the canonical file at `local/local_configuration.json`; generated evidence and cards are constrained to the ignored `local/` directory. Without that configuration, integration work is skipped rather than inferred.

No PAK, mesh, visual route, gameplay result, complete garment coverage, or global SCO/Sindae coverage is claimed. See [PUBLIC_CHECKPOINT.md](PUBLIC_CHECKPOINT.md) for the exact public boundary.
